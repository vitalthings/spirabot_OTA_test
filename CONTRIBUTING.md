# Contributing to Spirabot OTA Release Repository

Thank you for your interest in contributing to the Spirabot project!

## Important: Repository Purpose

**This repository is a release distribution repository only.** It exists solely to host compiled firmware releases and does not contain source code or accept code contributions.

## How to Contribute

### 1. Documentation Improvements

You can contribute by improving documentation in this repository:
- README.md enhancements
- RELEASES.md clarifications
- Security documentation updates
- Installation guides

To contribute documentation:
1. Fork this repository
2. Make your documentation changes
3. Submit a pull request with a clear description
4. Wait for review by maintainers

### 2. Release Process Improvements

Suggestions for improving the release distribution process are welcome:
- Better release templates
- Improved verification processes
- Automation suggestions
- User experience improvements

### 3. Reporting Issues

If you find issues with releases:
- Use the issue templates provided
- Include the specific release version
- Provide detailed reproduction steps
- Include relevant error messages or logs

## What NOT to Contribute

Please **do not** submit pull requests with:
- ❌ Source code changes (this repo has no source code)
- ❌ Firmware binaries (these are published through releases)
- ❌ Feature requests for the firmware (contact the development team)
- ❌ Bug fixes for the firmware code (not in this repository)

## Contributing to the Main Project

If you want to contribute to the Spirabot firmware development:
- This repository is **not** the place for code contributions
- Contact the development team for information about the main development repository
- The main repository is private and requires appropriate access

## Code of Conduct

### Our Standards

- Be respectful and inclusive
- Focus on constructive feedback
- Assume good intentions
- Help create a welcoming environment

### Unacceptable Behavior

- Harassment or discriminatory language
- Personal attacks
- Trolling or inflammatory comments
- Publishing private information

## Review Process

1. **Documentation PRs**: Reviewed by maintainers within a few days
2. **Issue Reports**: Triaged and responded to promptly
3. **Suggestions**: Evaluated based on benefit to users

## Getting Help

If you need help:
- Check existing documentation (README.md, RELEASES.md)
- Search existing issues
- Create a new issue with the appropriate template
- Contact maintainers if needed

## Questions?

If you have questions about contributing:
- Review this guide thoroughly
- Check the README.md for repository purpose
- Open an issue if something is unclear

Thank you for helping make Spirabot releases more accessible and user-friendly!
